# Parcours B2 · 20 天法语词汇

2506 个词条，保留原有 400 词，按 18 个主题、20 天和每天 5 组学习。

这是 GitHub Pages 发布仓库。网页内嵌字体、词库、动画和样式，保留完全模式与适合手机的极简模式。

无需登录即可翻卡学习、评分、收藏、复习和搜索。学习记录自动保存在当前浏览器，可在“设置与备份”导出、导入 JSON，并下载离线网页。

使用邀请码登录后，学习记录、复习日期、收藏与日历自动同步到专用 Supabase 项目。同一邀请码在多台设备和原网站之间共用学习进度，不同邀请码的记录分别保存。右上角的账户窗口可以同步、切换邀请码或退出本设备。

邀请码由服务器验证，网页不包含邀请码、账户密码或服务器秘密密钥。未登录时继续在本机学习，离线文件的记录单独保存。原网站旧账户的进度与新的邀请码账户分别保留。

考试倒计时的目标是北京时间 2026 年 11 月 14 日 00:00；这个入口使用设备当前时间。

Pages 从 `main` 分支发布；推送新的 `index.html` 后会自动更新。`.nojekyll` 关闭 Jekyll 内容转换。
